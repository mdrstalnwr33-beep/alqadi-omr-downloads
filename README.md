## الإصدار

APK 3 مبني من commit `ad7c790`، ويتضمن قالب ورقة إجابة A4 ثابت الإحداثيات بعمودين متجاورين، وتعليمات الطالب، وبيانات المدرسة والمعلم من الإعدادات، وعلامات المعايرة الأربع، مع إبقاء محرك OMR الحقيقي غير مدّعى حتى دمجه واختباره.

## التثبيت

نزّل ملف APK مباشرة على هاتف Android، ثم افتحه واسمح بالتثبيت من هذا المصدر إذا طلب النظام ذلك. ملف ZIP يحتوي على APK نفسه للمشاركة أو الحفظ.

ملاحظة: مصدر التطبيق محفوظ في مستودع منفصل، وهذه الصفحة مخصصة للتوزيع فقط.
